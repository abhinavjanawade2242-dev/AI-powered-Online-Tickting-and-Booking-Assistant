# PS-07 Developer Handoff Documents

This folder contains the agreed project specifications for our
AI-powered Online Ticketing and Booking Assistant.

## Documents

1. Complete PRD and MoSCoW
   - Project requirements, scope, priorities and acceptance criteria.

2. Frontend Screen Specification
   - Screens, UI components, user flows and frontend responsibilities.

3. Backend API and Database Specification
   - Proposed database structure, API endpoints and booking logic.

4. Four-Member Task Allocation
   - Individual responsibilities, deliverables and dependencies.

## Finalized Team Decisions

- Domain: Multi-venue
- Target audience: Students and college communities
- Platform: Web application
- Payment: Simulated payment only
- Inventory: Fixed ticket quantities, no assigned seats
- Languages: English, Kannada and Hindi

## Important

These documents are our shared development reference.
The API and database specifications are proposed designs.
Coordinate with the team before changing shared interfaces.
